# Dinnerpad

인터넷 없이 쓰는 PC용 런치패드 사운드보드입니다. 5×5 패드를 누르거나 **전역 단축키**를 누르면 지정한 사운드가 원하는 출력 장치로 재생됩니다. 게임이나 디스코드 등 다른 프로그램을 쓰는 중에도 단축키가 동작합니다.

## 다운로드

[Releases](https://github.com/10000sun/dinnerpad/releases)에서 받습니다. (Windows)

| 파일 | 설명 |
|---|---|
| `Dinnerpad-Setup-x.y.z.exe` | 설치형. 설정과 사운드는 `%APPDATA%\dinnerpad`에 저장됩니다. |
| `Dinnerpad-Portable-x.y.z.exe` | 설치 없이 실행. 설정과 사운드는 실행 파일 옆 `data` 폴더에 저장되므로 USB에 넣어 다닐 수 있습니다. |

## 사용법

- **패드 클릭**: 사운드를 재생하고 그 패드를 선택합니다. 같은 패드를 다시 누르면 처음부터 다시 재생합니다.
- **편집**: 선택한 패드의 이름, 사운드 파일(wav, mp3, ogg, flac, m4a, aac, opus), 색을 정합니다. 빈 패드는 여기서 새로 만듭니다.
- **삭제**: 선택한 패드와 사운드 파일을 지웁니다.
- **단축키**: 누른 뒤 원하는 키 조합을 입력합니다. `Ctrl+F1`, `Ctrl+Alt+A`처럼 여러 키 조합이 가능합니다. `Esc`는 취소, `Backspace`는 단축키 해제입니다.
- **우클릭**: 패드를 우클릭하면 편집, 삭제, 단축키 메뉴가 나옵니다. 아래 버튼과 같은 기능입니다.
- **상단 바**: 아래 토글과 `모두 정지` 버튼이 있습니다. 토글 상태는 저장됩니다.
  - `마이크 전송`: 마이크로 보낼 장치로 함께 재생할지 켜고 끕니다. 설정 탭에서 장치를 먼저 골라야 합니다.
  - `전역 단축키`: 다른 프로그램을 쓰는 중에도 단축키가 동작할지 켜고 끕니다. 키가 겹칠 때 임시로 끌 수 있습니다.
  - `항상 위`: 다른 창 위에 항상 표시합니다. 전체 화면(독점) 게임 위에는 표시되지 않을 수 있습니다.
- **설정 탭**: 출력 장치, 볼륨, 창을 닫을 때의 동작, 시작 프로그램 등록을 정합니다. 맨 아래 정보 칸에서 이 프로젝트의 GitHub 주소로 이동할 수 있습니다.
  - `Windows 시작 시 자동 실행`을 켜면 로그인할 때 트레이로 시작합니다. 설치형과 포터블에서만 쓸 수 있고, 포터블은 exe를 옮기면 다시 설정해야 합니다.

### 마이크로 소리 보내기 (선택)

설정 탭에서 장치를 두 개 고를 수 있습니다.

- **내가 들을 장치**: 내가 듣는 스피커나 헤드폰입니다. 기본값은 시스템 기본 장치입니다.
- **마이크로 보낼 장치**: 고르면 위 장치와 **동시에** 재생됩니다. 기본값은 사용 안 함입니다.

Windows에서는 프로그램이 마이크 입력으로 소리를 직접 넣을 수 없습니다. 아래 둘 중 하나로 소리가 마이크 입력에 도달하게 만드세요. 마이크로 보낼 일이 없다면 아무것도 설치할 필요가 없습니다.

- **오디오 인터페이스가 있는 경우**: 인터페이스의 재생 채널(예: `Playback 3/4`)을 고르고, 인터페이스 제어 프로그램에서 그 채널을 루프백 입력으로 연결합니다. 루프백 기능은 제품마다 다릅니다.
- **오디오 인터페이스가 없는 경우**: [VB-Cable](https://vb-audio.com/Cable/)(기부 방식 무료, 업무용 사용은 [약관](https://shop.vb-audio.com/en/content/3-Terms-of-use) 확인) 같은 가상 케이블을 설치하고, 마이크로 보낼 장치로 `CABLE Input`을, 디스코드 같은 프로그램의 마이크로 `CABLE Output`을 고릅니다.

내 목소리와 소리를 함께 보내려면 Voicemeeter 같은 믹서가 별도로 필요합니다.

### 단축키 제한

- 다른 프로그램이 이미 쓰는 조합은 등록되지 않습니다. 이 경우 해당 패드의 단축키 표시가 빨갛게 바뀌고 안내가 나옵니다.
- `Shift` 같은 수정키 하나만, 또는 키를 뗄 때의 입력은 단축키로 쓸 수 없습니다.
- 단축키는 프로그램이 실행 중일 때만 동작합니다. 창을 닫을 때 `트레이로 보내기`를 고르면(설정 탭에서 기본 동작을 바꿀 수 있습니다) 창만 숨기고 계속 실행됩니다. 트레이 아이콘을 클릭하면 창이 다시 열립니다. 우클릭하면 `마이크 전송`, `전역 단축키`, `항상 위`의 현재 상태(체크 표시)를 보고 바로 바꿀 수 있으며, `종료`를 누르면 완전히 종료됩니다.

## 개발

[Node.js](https://nodejs.org)가 필요합니다.

```bash
npm install
npm start       # 실행
npm test        # 단축키 변환·설정 정규화 테스트
npm run dist    # dist/ 에 설치형·포터블 exe 생성
```
