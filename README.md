# Dinnerpad

인터넷 없이 쓰는 PC용 런치패드 사운드보드입니다. 5×5 패드를 누르거나 **전역 단축키**를 누르면 지정한 사운드가 원하는 출력 장치로 재생됩니다. 게임이나 디스코드 등 다른 프로그램을 쓰는 중에도 단축키가 동작합니다.

## 다운로드

[Releases](https://github.com/10000sun/dinnerpad/releases)에서 받습니다. (Windows)

| 파일 | 설명 |
|---|---|
| `Dinnerpad-Setup-x.y.z.exe` | 설치형. 설정과 사운드는 `%APPDATA%\dinnerpad`에 저장됩니다. |
| `Dinnerpad-Portable-x.y.z.exe` | 설치 없이 실행. 설정과 사운드는 실행 파일 옆 `data` 폴더에 저장되므로 USB에 넣어 다닐 수 있습니다. |

## 사용법

- **패드 클릭**: 사운드를 재생하고 그 패드를 선택합니다. 같은 패드를 다시 누르면 처음부터 다시 재생합니다.
- **편집**: 선택한 패드의 이름, 사운드 파일(wav, mp3, ogg, flac, m4a, aac, opus), 색을 정합니다. 빈 패드는 여기서 새로 만듭니다.
- **삭제**: 선택한 패드와 사운드 파일을 지웁니다.
- **단축키**: 누른 뒤 원하는 키 조합을 입력합니다. `Ctrl+F1`, `Ctrl+Alt+A`처럼 여러 키 조합이 가능합니다. `Esc`는 취소, `Backspace`는 단축키 해제입니다.
- **출력 장치**: 상단 목록에서 고릅니다. 선택은 저장됩니다.
- **모두 정지**: 재생 중인 소리를 모두 멈춥니다.

### 단축키 제한

- 다른 프로그램이 이미 쓰는 조합은 등록되지 않습니다. 이 경우 해당 패드의 단축키 표시가 빨갛게 바뀌고 안내가 나옵니다.
- `Shift` 같은 수정키 하나만, 또는 키를 뗄 때의 입력은 단축키로 쓸 수 없습니다.
- 앱 창을 닫으면 프로그램이 종료되어 단축키도 멈춥니다. 단축키를 쓰는 동안에는 창을 최소화해 두세요.

## 개발

[Node.js](https://nodejs.org)가 필요합니다.

```bash
npm install
npm start       # 실행
npm test        # 단축키 변환 테스트
npm run dist    # dist/ 에 설치형·포터블 exe 생성
```
