# Dinnerpad 설계

## 목적
인터넷 없이 실행되는 PC용 런치패드형 사운드보드. 소스는 GitHub에 전부 공개되며 누구나 받아 쓸 수 있다.

## 목표
- 5×5 정사각형 패드 25개. 패드를 누르면 지정한 사운드가 설정한 출력 장치로 재생된다.
- 패드 아래에 편집, 삭제, 단축키 설정 버튼.
- 단축키는 `Ctrl+F1` 같은 조합 키를 지원하고, 다른 프로그램을 쓰는 중에도 동작하는 전역 단축키다.
- 배포는 설치형과 포터블 두 가지.

## 비목표
항상 트레이에 떠 있는 상주(트레이는 창을 숨긴 동안에만 표시), 페이드, 패드 페이지 전환, 자동 업데이트, 키를 뗄 때의 입력, 가상 마이크 라우팅.

## 접근 방식
| 안 | 장단점 |
|---|---|
| **A. Electron (선택)** | 출력 장치 선택(`setSinkId`)과 전역 단축키(`globalShortcut`)가 기본 제공된다. 용량이 약 100MB로 크다. |
| B. Python (PySide + sounddevice + pynput) | 가볍지만 mp3 디코딩과 장치 선택을 직접 붙여야 하고 PyInstaller 배포본은 백신 오탐이 잦다. |

Tauri는 Rust 미설치와 이점 부족으로 제외했다.

## 결정 사항
- 사운드 파일은 앱 데이터 폴더로 복사한다. 원본을 옮기거나 지워도 계속 재생된다. 설정에서 빠진 파일은 저장할 때 정리한다.
- 설정과 패드 배치는 `config.json`에 저장한다. 읽기에 실패하면 `.bak`로 백업한 뒤 새로 시작한다.
- 설치형은 `%APPDATA%\dinnerpad`, 포터블은 실행 파일 옆 `data` 폴더에 저장한다(`PORTABLE_EXECUTABLE_DIR`로 판별).
- 출력 장치는 두 개다. "내가 들을 장치"(기본: 시스템 기본)와 "마이크로 보낼 장치"(선택, 기본: 사용 안 함). 패드를 누르면 둘에 동시에 재생하고 볼륨은 각각 조절한다. 프로그램은 마이크 입력에 직접 소리를 넣을 수 없으므로, 오인페의 재생 채널 루프백이나 가상 케이블을 쓰고 설치는 사용자가 선택한다.
- 저장된 마이크용 장치를 찾지 못하면 기본 장치로 대신 보내지 않고 이번 실행에서만 쓰지 않는다. 설정은 그대로 둔다.
- 화면은 상단 바(패드/설정 탭, 모두 정지)와 본문으로 나눈다. 패드 우클릭 메뉴는 아래 버튼과 같은 기능이다.
- 같은 패드를 다시 누르면 처음부터 재생한다.
- 단축키를 입력받는 동안에는 전역 등록을 잠시 해제한다(등록된 조합이 앱에 도달하지 않으므로).
- 이미 다른 프로그램이 쓰는 조합은 등록에 실패하므로 해당 패드에 경고를 표시한다. 한 앱 안에서 같은 조합의 중복 지정은 막는다.
- 시작 프로그램 등록은 설정 탭 체크박스로 한다. 상태의 기준은 설정 파일이 아니라 OS의 로그인 항목이며, 패키징된 앱에서만 허용한다(개발 중 electron.exe가 등록되는 것을 막는다). 포터블은 `PORTABLE_EXECUTABLE_FILE`의 원본 exe 경로를 등록하고, 자동 실행은 `--hidden`으로 트레이에서 시작한다.
- 설정 탭 맨 아래 정보 칸에 버전, 라이선스, GitHub 주소를 둔다. 링크는 고정 주소만 외부 브라우저로 연다.
- 상단 바에 토글 3개(마이크 전송, 전역 단축키, 항상 위)를 둔다. 상태는 설정 파일에 저장한다.
- 앱은 단일 인스턴스로 실행한다. 창을 닫을 때의 동작은 설정(`closeAction`)으로 정한다: 매번 묻기(기본), 트레이로 보내기, 종료. 묻는 창에서 "다시 묻지 않기"를 고르면 그 선택이 설정에 저장된다. 트레이로 보내면 창만 숨기고 아이콘을 띄우며, 클릭하면 창을 다시 열고, 우클릭 메뉴에서 토글 3개의 상태를 체크 표시로 보여 주며 바로 바꿀 수 있고, 종료로 완전히 끝낸다. 메인 프로세스가 바꾼 값은 `config-patch`로 렌더러에 알려 두 쪽 설정을 맞춘다. Windows 종료·로그오프는 막지 않는다.
- 라이선스는 MIT.
